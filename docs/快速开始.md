# 五分钟开始

## 先试示例

1. 打开 `example-星港窗户演示`。
2. macOS 双击「启动面板.command」。如果系统未把它作为可执行脚本打开，可在终端进入该目录，运行 `python3 management/server.py`。不要更改系统安全设置。
3. 浏览器自动打开；若没有打开，复制启动窗口里的 `http://127.0.0.1:端口` 到浏览器。此地址只在本机使用。
4. 查看任务、版本审核、交付和批次。示例所有内容与费用均为虚构。
5. 编辑记录后点「确认修改」，再点右上角「保存到项目」。看到修订号增加、未保存提示消失，才表示已落盘。
6. 浏览器重开仍能读取保存状态。关闭本地服务：在启动窗口按 Ctrl+C。

## 建立真正的新项目

最简单的方法：复制整个 `template` 文件夹到自己选择的位置，改文件夹名，打开其中的启动工具，编辑项目名称、范围和验收标准。不要复用示例作为空白母版。

也可双击包根目录「新建项目.command」，输入目标目录和项目名称。路径按提示粘贴完整文字，不要附带引号；拖入路径可能产生转义字符，遇到失败时请直接复制 Finder 显示的路径。

终端方式（将路径替换为你自己的）：

```sh
python3 /模板包/tools/init_project.py /项目位置/新项目 --name "项目名称" --dry-run
python3 /模板包/tools/init_project.py /项目位置/新项目 --name "项目名称"
```

Windows：安装 Python 3.9+ 后双击项目「启动面板.bat」；或在命令提示符运行 `py -3 management\server.py`。Windows 启动脚本已提供，但本次没有 Windows 实机测试。

## 日常顺序

填写概览 → 建材料批次（如有临时材料） → 建任务 → 登记具体版本 → 审核该版本 → 登记交付并验收 → 写结项汇总（费用可空） → 保存并封版 → 生成清理预览。

新版本要重新审核。审核通过的版本文件请保留，不要原地覆盖；必要时在 50-versions 保存阶段包。清理预览不执行删除。AI 写状态请用 `python3 management/cli.py`；已建项目升级见详细指南「升级已建项目」。

浏览器若询问下载许可，表示「导出 JSON」想把数据下载到本机，和「保存到项目」不同。无需为日常保存启用持久下载权限；直接使用本地服务保存即可。
